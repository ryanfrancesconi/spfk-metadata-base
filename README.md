The metadata value types used by [spfk-metadata](https://github.com/ryanfrancesconi/spfk-metadata):
tag keys and values, the audio file description, BEXT, iXML, markers, artwork, and the errors and
dirty flags a save reports. It contains no TagLib or file-writing code. spfk-metadata depends on
this package and re-exports it.

## About

Spongefork is the personal software projects of musician and developer [Ryan Francesconi](https://spongefork.com). Dedicated to creative sound manipulation, his first application, Spongefork, was released in 1999 for macOS 8. From 2026, Spongefork returns as his software container for more musical experimentation. In addition to [software releases](https://spongefork.com/shadowtag/), open source components can be found on his [GitHub page](https://github.com/ryanfrancesconi).
